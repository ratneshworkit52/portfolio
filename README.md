## Deploying to GitHub Pages
1. Publish this repository on GitHub.
2. Open the repository `Settings` > `Pages`.
3. Set the source to the `docs/` folder on the `main` branch (or the branch you are using).
4. Save the settings.
5. The site will appear at `https://<username>.github.io/<repository-name>/`.

## Included Files
- `docs/index.html` — Portfolio homepage
- `docs/styles.css` — Styling for the portfolio
- `docs/script.js` — Minimal interaction logic for responsive navigation
- `docs/Ratnesh_Shukla_27-Jul-2026.pdf` — Downloadable resume
- `.nojekyll` — Ensures GitHub Pages serves the site without Jekyll processing

## Customization
Edit `docs/index.html` and `docs/styles.css` to update the content, branding, or visual style.
